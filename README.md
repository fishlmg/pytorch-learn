# PyTorch 学习练习

PyTorch 深度学习基础练习集合，覆盖张量操作、`nn.Module`、`nn.Sequential`、数据加载、训练循环与模型推理。

## 文件结构

```
├── 1.py               # 基础语法练习
├── nn_base.ipynb      # nn.Module 网络构建基础
├── sequential.ipynb   # nn.Sequential 快速搭建
├── train.ipynb        # 完整训练流程
├── test.py            # 模型测试
├── infer.py           # 模型推理
└── *.pth              # 训练权重（不入库，见 .gitignore）
```

## 快速开始

```bash
pip install -r requirements.txt
jupyter notebook
```
